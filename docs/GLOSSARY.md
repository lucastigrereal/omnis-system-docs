# 📖 Glossário OMNIS

| Termo | Definição |
|---|---|
| **Missão** | Uma tarefa de alto nível que o OMNIS executa do início ao fim |
| **Wave** | Uma unidade atômica de trabalho dentro de uma missão de desenvolvimento |
| **Mission Package** | O artefato final: código + testes + documentação |
| **PatternRecord** | Registro de aprendizado de um projeto no Akasha |
| **Allowed Files** | Lista exata de arquivos que um Executor pode tocar em uma wave |
| **Guardrail** | Regra de segurança ou qualidade que o OMNIS não pode violar |
| **Squad** | Time dinâmico de agentes montado para uma missão específica |
| **Skill** | Capacidade atômica reutilizável (ex: web_search, code_execution) |
| **Control Plane** | Camada que orquestra todos os agentes e módulos |
| **Event Bus** | Sistema de mensagens pub/sub entre módulos |
| **Checkpoint** | Momento de pausa para aprovação humana |
| **dryrun** | Executar uma ação sem efeito real para validar antes de aplicar |
| **Akasha** | A memória operacional do OMNIS (nome inspirado em "registro akáshico") |
| **App Factory** | Módulo que transforma ideias em aplicativos |
| **OMNIS Verse** | O ecossistema completo: holding digital + todos os produtos |
| **Capability Forge** | Mecanismo de auto-expansão de capacidades do OMNIS |
| **Economic Brain** | Componente de controle de custo de tokens por missão |
| **Worktree** | Branch Git isolada para execução paralela de waves |
| **PRD** | Product Requirements Document — especificação do produto |
| **Blueprint** | Especificação técnica: stack, arquivos, contratos de API |
| **ADR** | Architecture Decision Record — registro de decisão arquitetural |
| **SWE-bench** | Benchmark padrão de mercado para medir qualidade de coding agents |
| **Human-in-the-Loop** | Modelo onde humano aprova decisões críticas, sistema executa o resto |
| **Plan-then-Execute** | Padrão agêntico: planejar completamente antes de qualquer execução |
| **RAG** | Retrieval-Augmented Generation — busca em base de conhecimento + LLM |
| **LangGraph** | Framework para grafos de agentes stateful com checkpoints |
| **OpenHands** | SDK open-source de execução autônoma de código (72-77% SWE-bench) |
| **CrewAI** | Framework para times de agentes com papéis e memória |
| **n8n** | Plataforma de automação de workflows self-hosted |
| **Dify** | Plataforma de RAG e workflows reutilizáveis por departamento |
